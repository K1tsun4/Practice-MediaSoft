# Practice-MediaSoft
Данный репозиторий создан для выполнения заданий на языке программирования Java в компании MediaSoft Mobail.
## Задачи на практику:
1. Практическое изучение базового синтаксиса и основ языка Java - создание простого приложения с использованием примитивных и объектных типов, условий и циклов.
2. Практического изучение использования коллекций и StreamAPI в Java - создание приложения по управлению коллекцией объектов и применении преобразования элементов, поиска и сортировки по ней
3. Практическое изучение принципов ООП и абстракций в Java - создание приложения с использованием обобщеных типов, интерфейсов и абстрактных классов, использование сборщиков и обработки исключений.
4. Практическое изучение лямбда-выражений и функциональных интерфейсов - создание приложения с использованием функциональных интерфейсов, лямбда-выражений и аннотаций.
